# J21 – Telecommunications Service Provisioning and Activation System

## Project Overview
A web-based application designed to automate telecommunications service provisioning and activation workflows.

## Technology Stack
- Frontend: React.js
- Backend: Java 17, Spring Boot 3
- Database: MySQL 8
- ORM: Spring Data JPA / Hibernate
- Build Tool: Maven
- API Testing: Postman

## Project Modules
1. Service Catalog Management
2. Order Capture and Validation
3. Workflow and Provisioning Automation
4. Service Activation and Testing

## Project Structure
- frontend/ – React application
- backend/ – Spring Boot application
- database/ – SQL scripts and ER diagram
- docs/ – Project documentation and test reports
